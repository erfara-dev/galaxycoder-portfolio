01Overview

A reusable website solution

The project aims to adapt an earlier single-vendor booking website into a flexible foundation that can be customized for different businesses. It explores two distinct application directions—booking and ordering—built around the same reusable website foundation.

This is separate from LapanganKu, which is a multivendor booking and management project.

02Project motivation

Adapt a foundation to different businesses

The goal is to make the earlier single-vendor booking website more reusable, so its presentation and business-specific information can be adapted instead of treating it as only one booking website.

03System direction 01

Booking System

One planned direction is a booking system. The following are potential use cases for this direction, not claims that each has been implemented:

  • Sports field booking
  • Accommodation and lodging reservations
  • Rental services
  • Studio reservations

04System direction 02

Ordering System

A separate planned direction is an ordering system. Its potential use cases include:

  • Restaurant websites
  • Café ordering
  • Food ordering
  • QR-based table ordering

The ordering direction is distinct from the booking system; these are not presented as one combined application.
