01Overview

The idea

The concept is to use an Android smartphone as a touch-based game controller connected to a Windows laptop over USB. A phone app would provide the input surface, while a Windows companion application would handle communication and translate supported touch controls into corresponding PC controls.

This page documents a direction to explore, not a working application.

02Motivation

A controller that fits the player

Mobile touchscreens and Windows games use different input models. This idea explores whether a configurable phone interface and a companion utility could bridge that gap, letting a player arrange touch controls and map them to supported PC inputs.

03Proposed concept

Phone input, Windows companion

The proposed system has two parts: an Android app for a customizable on-screen control layout, and a Windows companion that receives input over USB and maps supported controls. The communication protocol, input integration approach, and device support would need to be researched and validated before implementation.
